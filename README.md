# PaperAnimators

A free browser-based text animation tool built with vanilla 
JavaScript and Canvas API.

## What it does

- Typewriter Effect
- Word Sphere (3D rotating word cloud)
- Newspaper Mode
- Magazine Letters
- Text Trail
- Text Reshuffle
- Google Search Animator
- Quote Card Generator
- Country Map Visualizer
- Number Counter

## How to use

No installation needed. Open directly in your browser:

[Try it free here](https://paperanimators.in)

No signup. No watermark. No file uploads. 
Everything runs on your device.

## Built with

- Vanilla JavaScript
- HTML5 Canvas API
- CSS3
- WordPress
